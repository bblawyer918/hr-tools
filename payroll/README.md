# 薪資結算儀表板（payroll-dashboard）

物業／保全公司內部薪資試算工具。雙擊 `薪資計算.html` 就能用（Excel 讀取元件在 `../lib/`，不用網路）；資料只在本機瀏覽器計算，不上傳。

- 狀態：v2（2026-11-01）——拿掉所得稅；扣款改為勞健保、勞退自提、制服代扣、團險、職工福利金；雇主負擔加職災 0.25%（預設）與墊償基金
- 原始位置：`~/Projects/payroll-dashboard`（2026-11-01 搬進 hr-tools；v1 備份留在原資料夾的 `_備份/`）
- 範例：`../samples/薪資計算_範例假資料.csv`
- 參考：NUEIP 薪資系統功能分類（只參考功能，不複製畫面）
- 費率：115 年（2026）。**116 年 1 月 1 日起最低工資調為 30,900 元，級距表公告後要更新 `薪資計算.html` 裡的 `RATES` 區塊**

## 匯入欄位
必填：`姓名`、`本薪`。其餘選填：員工編號、部門、伙食津貼、職務加給、全勤獎金、加班費、其他加項、請假扣款、制服代扣、制服同意書（填「有」）、團險、福利金、其他扣項、健保眷屬數、勞退自提率（%）、勞保投保薪資、健保投保金額、勞退提繳工資。
「福利金」留白時，依畫面上的扣繳率（預設 0.5%，職工福利金條例§2Ⅰ③）自動算；有填就用填的。
投保欄位留白時，依「本薪＋伙食＋職務加給＋全勤」對照級距；有填時，會檢查是否低於應投保級距（高薪低報）。

## 已知限制（v1 不處理）
到離職未滿月按日計算、部分工時級距、二代健保補充保費、所得稅（v2 起不計算）、加班費／特休結算。職災預設 0.25%（行業別 48 類），50 人以上單位若適用實績費率，請改成繳款單上的費率。
勞退、職災提繳級距沿用健保級距（勞退上限 150,000、職災上限 72,800），尚未逐級對照官方勞退／職災分級表。
