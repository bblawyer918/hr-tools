# hr-tools（人資小工具組）

物業／保全公司人資用的離線小工具。每個工具都是一個網頁檔，**雙擊就能用，不用安裝、不用網路**；資料只在這台電腦的瀏覽器裡計算，不會上傳。

> 2026-11-01 建立。功能分類參考 NUEIP 的 AI 指令範本與排班模組，只參考功能，不複製畫面。

## 工具清單

| 資料夾 | 工具 | 讀什麼檔 | 做什麼 |
| :-- | :-- | :-- | :-- |
| `schedule/` | 排班設計工具 | 自己建班別、人員 | 自動排班、檢查人力與工時、匯出 Excel |
| `weekly-schedule/` | 排班週報 | 排班設計工具匯出的 Excel | 一週一社區的班表、每人本週工時、複製 LINE 訊息 |
| `attendance/` | 出勤管理儀表板 | 出勤紀錄（標準格式） | 遲到、早退、缺卡、曠職、加班、請假日曆 |
| `morning-report/` | 每日出勤晨報 | 出勤紀錄（標準格式） | 今天誰請假、誰遲到、昨天的異常，複製 LINE 訊息 |
| `turnover/` | 人才流動洞察 | 員工名冊 | 離職率、哪個社區人走得最多、年資結構、留任率 |
| `training/` | 回訓人員管理 | 員工名冊＋訓練紀錄 | 保全職前／每月在職、職安、急救、防火管理人、事務管理人員回訓到期提醒 |
| `approvals/` | 簽核追蹤日報 | 簽核紀錄（也可手動新增） | 卡在誰手上、等了幾天、複製催簽訊息 |
| `payroll/` | 薪資計算 | 薪資 Excel／CSV | 勞健保、勞退、制服代扣、團險、福利金、雇主負擔（細節見 `payroll/README.md`） |

共用元件放在 `lib/`（Excel 讀取元件 SheetJS 0.18.5、共用樣式與函式）。**整個資料夾要一起搬**，只拷一個 html 會讀不到 `lib/`。

## 範本與假資料（`samples/`）

- `*_範本.xlsx`：空白範本，照欄位填真實資料。
- `測試假資料_*.xlsx`、`薪資計算_範例假資料.csv`：全部是虛構人名、公司、社區，可以先拿來試玩。
- `_gen_samples.py`：產生假資料的腳本（改了欄位要重跑）。

## 真實資料放哪裡（重要）

```
hr-tools/
├─ _local/      ← 真實員工資料只放這裡（不會進 Git、不會上傳 GitHub）
├─ samples/     ← 只放範本和假資料（會上傳）
└─ 各工具資料夾 ← 只放程式（會上傳）
```

- `.gitignore` 已經擋掉 `_local/`，也擋掉 `samples/` 以外的所有 Excel／CSV，避免不小心把真資料推上去。
- 「簽核追蹤日報」的資料存在瀏覽器裡（localStorage），換電腦或換瀏覽器不會跟著走；要搬就先按「匯出 Excel」，到另一台再匯入。

## 公司電腦第一次使用

1. 打開「命令提示字元」或 Git Bash，貼上：
   ```
   cd %USERPROFILE%\Projects
   git clone https://github.com/bblawyer918/hr-tools.git
   ```
   （Git Bash 的第一行改成 `cd ~/Projects`；`Projects` 資料夾不存在就先建立）
2. 打開 `hr-tools`，在裡面建一個 `_local` 資料夾，把公司的真實 Excel 放進去。
3. 雙擊要用的工具 html（建議用 Chrome 或 Edge），把 `_local` 裡的檔案拖進去。

之後每天開工先在 `hr-tools` 裡跑 `git pull` 抓最新版；改了工具要推回 GitHub 時，只 `git add` 改過的 html／js，不要用 `git add .`。

## 法規依據（回訓人員管理）

保全業法 §10-2；職業安全衛生教育訓練規則 §17、§18、§19；防火管理人訓練與專業機構登錄及管理辦法 §3；公寓大廈管理服務人管理辦法 §5。工具裡的規則表會列出各項的週期與時數，法規修正時要同步改 `training/回訓人員管理.html` 的 `TYPES`。
